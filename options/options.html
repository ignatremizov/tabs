Client ID

Each browser you use needs its own unique identifier. Use something very short with no spaces or punctuation, ideally 3 letters or less, because it will become part of the ID for each tree node and transaction created by that browser. For example:
  • pc: Your desktop computer.
  • nb: Your notebook computer.
  • w: Your work computer.

Keyboard Shortcuts

These shortcuts apply when the side panel has focus. Click a field and press a key combination. Use Backspace/Delete to clear and Esc to cancel.

Some key combinations may be reserved by your browser or OS and won't work.

Firefox also has global extension shortcuts in “Manage Extension Shortcuts”. These are separate from the in-panel shortcuts above and only include a few commands like Toggle Side Panel, Unload current tab, and Add highlighted text to current tab’s notes.

Backups

Backup files can either be human friendly (easier to view in a text editor) or not (smaller files).

Automatic local backups are saved to your "Downloads" folder if enabled. Set to 0 to disable this. 1 day = 24, 1 week = 168, 1 month = 720.

Import Session Files

Old session backup files can be imported here. Note that imported sessions will add to your current session, not replace your session. If you have sessions from a few different browsers and want to merge them into one, import each session and they'll all get added to one big tree. Be prepared to do some manual re-organization and de-duplication afterward though, because the import process does not attempt to de-duplicate for you.

To restore old session backups from this extension, unzip them first and then put them here.

File decompression is not directly supported by the browser, so if the backup file is compressed, unzip it first. If it uses gzip (a .gz extension), unzip it with a command like gzip -d myfile.json.gz or gunzip myfile.json.gz. If the file is compressed with zstd (uses a .zst or .zstd extension), unzip it with zstd -d myfile.json.zst or unzstd myfile.json.zst.
