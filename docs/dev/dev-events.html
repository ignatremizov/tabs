Event Flow (Developer Notes)

TKTSTO uses two main event systems: message passing between the background service worker and views, and UI input events (keyboard/mouse) inside the TreeView.

Background & view messages

The emit(name, args) helper in common/common.js wraps api.runtime.sendMessage(). It adds msg and sourceId to the payload and retries on transient MV3 failures.

Message naming conventions

  • bkgd_* — view to background requests (expect responses).
  • tree_* — background to view state notifications.
  • treeview_* — view-facing UI notices (status text, etc).

Loop prevention

Each emit() call includes a unique sourceId. Tree.onMessage() ignores messages whose sourceId matches its own to prevent feedback loops.

MV3 resilience

When no views are open, the service worker can be terminated between events. emit() retries up to emit.maxTries with emit.retryDelayMs backoff. If all retries fail, it reports a warning via a DOM event and optional hook:

  • tktsto_emit_failure — a CustomEvent on window with a detail.status message.
  • emit.onFailure — optional callback for tests/telemetry.

The TreeView listens for tktsto_emit_failure and updates the status bar to warn the user that background actions may be delayed.

Examples

// View requests full tree from background:
const tree = await emit('bkgd_getTree');

// Background notifies all views about a change:
emit('tree_nodeAdded', { parentId, index, node });

// Background sends a UI status update:
emit('treeview_status', { status: 'Ops backlog detected', severity: 'warn' });

UI input events

Keyboard and mouse events are normalized by common/events.js into action names like Shift+Ctrl+P or MouseDblClickLeft. TreeView maps those strings to actions via defaultKeyBindings and keyBindingActions.

Where to look

  • common/common.js — emit() transport.
  • common/tree.js — Tree.onMessage() handler.
  • bkgd/bkgd.js — background listeners & status messages.
  • view/treeview.js — view handlers & input bindings.
  • common/events.js — event name builder for UI inputs.
